WorkBox 工作箱 1.0.0 · Windows 干净安装版

使用范围
适用于 Windows 10 1809 或更新版本，以及 Windows 11 的 Intel/AMD 64 位电脑。
本包不适用于 32 位 Windows、Mac 或 ARM 设备。
已包含运行所需的 Python、Qt 和相关动态库，不需要单独安装开发环境，可离线使用。

安装与启动
1. 将下载的 WorkBox 安装程序复制到另一台电脑，双击打开中文安装向导。
2. 建议保留默认安装位置，按向导安装。可选择创建桌面快捷方式。
3. 安装完成后可直接启动；以后双击桌面或开始菜单中的“WorkBox 工作箱”。
4. 日常启动显示悬浮球，点击打开项目管理。双击项目会打开对应工作文件夹。

项目操作与交付记录
项目页左侧选项目，右侧只显示对应文档。右击项目名，可管理状态、加急、备注与日期、名称、原文、目录、交付和归档恢复；菜单键也可操作焦点项目。
右键“确认交付…”打开短对话框，可选择归档项目工作文件（无需 ZIP）或明确的 ZIP 版本，默认取消。材料复制和校验成功后才更新交付记录，原件保留。
首页“今日交付”只统计首次有效交付发生在北京时间今天的项目。同一项目在全历史中只计首次有效交付，补交保留记录但不再增加项目数。
点击“今日交付”进入交付记录管理，可选择日期、全部日期、搜索项目或批次，查看所选项目的明细。
误记可选择一条或多条明细后撤销；勾选“显示已撤销”后可恢复。每次撤销或恢复都需确认，默认取消。
撤销新记录后，项目会退回待交付并清除当前交付标记；原始记录、项目文件和归档文件保留，已归档项目仍保持归档。重复撤销已撤销记录不产生副作用。统计按全历史有效记录重新计算，较晚的有效记录可能成为首次。
恢复只恢复记录的统计有效性，不会自动将项目改为已交付；需要时请按实际情况再次确认交付。旧撤销记录不会在启动时自动改写。

这是干净安装包
不携带原电脑的项目、工作文件、压缩包、数据库、交付记录或设置。
首次启动项目数为 0，数据和目录会在本机自动创建，不需要账号或服务器。

文件位置与备份
默认程序位置：%LOCALAPPDATA%\Programs\WorkBox
默认数据位置：安装目录\data
工作项目：安装目录\data\工作项目
交付归档：安装目录\data\ZIP归档
在工作箱“工作设置”中可以选择其他本地工作和归档目录。
备份时先在工作箱点击“退出”，再复制整个 data 文件夹；如果选择过其他工作或归档位置，也要备份这些位置。
不要单独移动 WorkBox.exe，程序需要同目录的 _internal 文件夹。
更新时保留当前安装目录的 data，不要用旧备份直接覆盖正在使用的新数据。

工作规则配置
“工作设置”还可调整自动建项、ZIP自动交付、每项目最少文件数和文件稳定等待时间。
默认开启自动建项和自动交付；每项目至少4个实际文件时自动交付，默认等待10秒稳定后归档。
关闭自动建项后，先创建或选择项目再收件；关闭自动交付后，新ZIP仍归档并进入待交付，可在项目右键人工确认。
规则按本机数据目录独立保存，修改后不回写旧ZIP判定或交付历史。恢复默认规则需要点击保存后生效，目录不会被重置。
文件夹收录保留子目录；不同材料文件名即使内容相同也分别保留。同名同内容可复用副本，原件始终保留。

重装与卸载
更新或重新安装前，请先在工作箱点击“退出”，再运行安装包，使用原安装位置。
重装不会覆盖 data。卸载入口位于 Windows“已安装的应用”及开始菜单。
卸载只移除软件文件，保留使用过程中产生的 data 和外部工作/归档文件。
安装位置需要当前用户可写，不建议改到 Program Files 等受保护目录。
旧安装包用于留档；如需回退，请恢复对应备份，旧版不能识别新增的工作规则。

版本与验证边界
版本为 WorkBox 1.0.0，不读取微信聊天，不提供云同步。共享文件访问使用Windows已有权限。
当前安装包没有商业数字签名；请保留并核对随包提供的 SHA256 校验文件。
本机验证的具体结果见随包验证说明；尚未在另一台实际设备上测试。

第三方组件的许可和来源见 THIRD_PARTY_NOTICES.md 及 licenses 文件夹。

删除项目与材料识别
普通文件可按明确材料尾缀“申请表”“申请书”“操作手册”“用户手册”匹配项目；尾缀后可带“重新下载”“下载说明”或“下载链接”。已有完整名称优先，版本尾缀逐层剥除，不进行模糊匹配。未删除的正确项目优先于仅在“已删除”中存在的错误完整名项目。
右键“删除项目…”的确认框默认取消。确认后项目移入“已删除”，原磁盘目录、工作文件、ZIP、原始交付和统计记录都保留；已删除项目从日常、归档、全部项目列表和总项目数中排除。在“已删除”筛选下右键“恢复已删除项目”，会恢复删除前的归档状态，不改变项目状态。已删除项目不可编辑或批量归档/恢复；受保护目录和名称不会被静默自动重建。
