# WorkBox Studio 与名单核对

## 目标与选择
维护者要求借鉴 BOX fork 的实用能力并将整体与组件 UI 升级，保留独立风格。本轮采用原生 Qt / 既有 Fluent 适配层，不整树移植 fork。设计选择由本轮实现端提出：暖白纸面、石墨深色、靛蓝主操作，结构清楚但不增加统计大卡片和多层侧栏。

备选：仅给旧控件换色，不能解决缺项核对；照搬 fork 的会话/任务总表，会改变原项目身份和交付语义。选择既有项目双栏 + 独立名单核对工作台 + 共享视觉系统。新的核对入口不取代项目管理，不恢复退役任务组。

## 功能边界
- 读取 XLSX / CSV / TSV，选择工作表、名称列和日期列。保留源行、重复名称和完整名称；名称比较使用主线 NFKC、大小写及连续空白规范，不模糊匹配。
- 明确年份的日期才参加时间范围筛选。无年份、非法日期和无日期单独提示，不暗补本年、不悄悄沿用上一行日期。
- 名单核对只读取当前项目；区分未收录、同名待确认、已归档、已删除和已关联。项目状态与材料结果分开。
- 点击检查材料才读取已关联项目的当前文件及已保存材料规则。不配置规则不判收齐，读取失败不等于缺零份。复用主线 material_matching，不读文档正文、不执行文件、不改变原文件或交付状态。
- 本轮清单只在当前窗口内保留；导入不是新建项目，不存到生产任务总表。关闭并重新打开同一会话窗口保留当前结果；软件重启需重新选择清单。
- 核对后台执行、可取消；新导入失败保留原结果。使用标准 Qt 表格、选择、滚动和文件对话框。退出等待工作线程停止。

## 视觉覆盖
Studio 色彩变量由一个模块提供，theme.py 仍是唯一外观所有者。统一原生与 Fluent 按钮、输入、组合框、分段筛选、菜单、表格、弹窗、标签、进度与状态反馈。保持可见键盘焦点、禁用态可读、长名完整 tooltip/辅助名称；正常文本对比度至少4.5:1。保留浅/深/系统三态，不写库级配置、不自绘滚动行为。

主窗口保留顶部工作区导航与左项目/右文件结构，轻量标题条、靛蓝选中态及柔和分隔；窄窗继续原清单/详情切换。材料核对使用紧凑顶部文件映射区、中部结果表、底部说明及显式检查按钮。

## 非目标与协作
不复制 fork 数据库、直接覆盖历史选项、解压、便携更新或任务新建逻辑。不改另一端 #66 当前文件/历史文稿处理，只消费主线公开文件列表API。UI源码进入main与安装包发布分开记录；本轮不复用已发布构建号重打包。
