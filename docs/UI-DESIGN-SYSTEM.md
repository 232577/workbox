# WorkBox 桌面设计系统

本轮目标：将现有项目工具提升为层次清楚、操作可发现、状态可信的桌面工作台。不是整树替换，不改变交付语义、数据结构或用户文件。

## 参考与取舍

2026-11-03 实际查阅的官方参考：
- Windows 内容布局与间距：https://learn.microsoft.com/en-us/windows/apps/design/basics/content-basics
- Windows 设计基础：https://learn.microsoft.com/en-us/windows/apps/design/guidelines-overview
- Fluent 按钮：https://fluent2.microsoft.design/components/web/react/core/button/usage
- Fluent 对话框：https://fluent2.microsoft.design/components/web/react/core/dialog/usage
- Fluent 无障碍：https://fluent2.microsoft.design/accessibility
- VS Code 操作分组：https://code.visualstudio.com/api/ux-guidelines/editor-actions

采用的是信息组织与交互原则，不复制品牌、商标或网页代码。单纯换色不能解决发现性和反馈；重写成网页壳会引入额外打包/更新风险。因此本轮在现有 PySide6、锁定 QFluentWidgets 和 Qt 原生菜单/滚动上增量升级。用户要求直接继续实现；下述具体方案是实现端的设计选择，不冒称逐项经过另一次用户确认。

## 覆盖范围

| 层级 | 规范与落点 |
| --- | --- |
| 基础 | 4/8/12/16/24间距节奏，固定字号，浅深语义配色，柔和表面与边框；不通过放大窗口放大文字 |
| 导航与布局 | 稳定侧栏、清楚的页标题/摘要、上下文动作；小窗口保留操作与原生滚动 |
| 按钮 | 一处主要动作；次要/危险动作区分，禁用有原因；原生键盘行为不被重绘破坏 |
| 输入 | 可见标签/无障碍名称、焦点轮廓、禁用/只读反馈；数字及下拉文字不裁切 |
| 数据组件 | 表头与行层级、选择/悬停/焦点分离、可拖列宽、长名工具提示、滚动锚点保持 |
| 反馈 | 中性/忙碌/成功/警告/失败的文本和颜色双重表达；不能用旧成功结果代表新一轮操作 |
| 对话框 | 标题、可滚动内容、固定动作区；保留取消、关闭与线程安全，不自动保存规则 |
| 特定页面 | 主工作台可见材料入口；材料检查概览、缺项筛选、显式复制摘要；更新窗口阶段与构建信息 |

公共外观覆盖现有按钮、输入框、选择器、复选框、页签、表格、列表、菜单、滚动条、进度条、提示、设置卡片和标准弹窗。重点页面重排不表示每个旧业务窗口都重新设计了流程；未验收部分不能宣称完成。

## 功能与安全边界

材料检查只读取登记项目的文件元数据。缺项筛选只影响展示，不改计数。复制摘要仅由用户点击触发，不读剪贴板、不监控剪贴板、不自动上传。规则编辑使旧检查失效，关闭不自动保存。项目名按纯文本显示，长名可完整查看工具提示。

在线更新必须区分检查、下载、校验、准备安装及失败；保留现有HTTPS、SHA-256、目录一致性、恢复点和安全退出协议。新UI代码进入main不等于旧安装版更新。先验证准确提交及新冻结产物，再尝试本机升级，不覆盖其他端未提交的发布工作。

## 验收

新增回归先失败再实现；现有主题/列宽/滚动/保存/关闭/更新回归保持。实际Windows Qt截图采用隔离匿名夹具，覆盖浅深、常规/窄窗、空态/缺项/成功/错误与主题切换。完整Windows及网站/仓库检查、当前SHA云端CI分别记录。冻结安装、实际本机升级及另一设备验收独立记录，不相互冒充。
