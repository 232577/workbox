# WorkBox Studio · 名单核对

这是源码中的新工作台能力；安装版是否包含，以正式构建的发布说明为准。

## 使用
在项目页顶部点击 **名单核对**，导入 XLSX、CSV 或 TSV，选择工作表、名称列与日期列。自动建议仅用于预填，可修改后重新核对；旧 XLS 需另存为 XLSX，公式需粘贴为值。

表格保留原始行号和重复名称，按完整名称及确认过的旧名匹配已有项目。唯一有效项目显示“已关联”；不存在、多个同名、归档、删除或目录待恢复分别提示。导入不会新建、合并、改名或交付项目，不会整理任何实际文件。

**检查本次材料**读取每个关联项目已保存的材料规则和当前文件。没有规则显示“未配置规则”，不默认套用五件材料；读取异常显示“读取不完整”，不能作为收齐证明。项目状态和材料状态分别显示。双击已关联项目，或点击“材料规则与详情”，进入原有材料检查；保存规则仍须用户明确点击原窗口的保存按钮。

结果是本次读取快照，文件更新后点击重新检查。原表只有月日、无日期或非法日期时不会补年份，也不把上一行日期自动传递下来；使用日期范围时只选有明确完整日期的记录。日期范围包含起止日，界面显示未计入的日期缺失条目数。

清单在本次程序会话内保留；关闭核对窗口后再次打开可继续查看，程序重启后需重新导入。读取在后台执行，可取消；失败或取消保留上一次结果，不返回半截成功。最多10MB、5000行/100列、2000名称，单次材料扫描最多200个唯一项目。

## 视觉体系
独立 Studio 风格使用暖白纸面、石墨深色和靛蓝重点色。`studio_design.py` 提供语义颜色与最终公共样式层，`theme.py` 仍负责浅色/深色/系统和调色板，`control_styles.py` 负责 Fluent / 原生适配。整体双栏、窄窗切换和原生滚动保持。

覆盖项目/文件面板、顶部导航、主次按钮、输入与组合框、数字输入、状态筛选、表格表头与选择、菜单、提示、进度、弹窗和设置分组。颜色同时配合明确文字，异常与未知不等同于零。键盘焦点、禁用态和主题切换保留输入/选择。

## 借鉴与保留
交互目标参考 t971226-alt/workbox BOX build60（`64e5ce8`）的外部清单核对和缺项总览，本实现按 WorkBox 项目身份、已有材料检查与线程生命周期重新编写。没有复制其任务数据库、覆盖删除历史、解压、便携更新或同名新建流程。

本轮没有实现自动目录绑定、Word/PDF依赖失效、跨会话保存名单或未经确认的全库扫描。这些不是现有版本已提供能力。材料齐全不等于内容合格，也不改变交付与工作量。
