# 交付项目表格

主窗口的交付记录页面提供“导出表格”，保存为本机 Excel 工作簿（`.xlsx`）。它导出全部有效交付项目，不受页面日期、关键词或显示撤销记录选项影响。取消保存不会开始任务。

“交付项目”表每个项目一行。以合并后的项目编号归并，不按名称去重；同名的独立项目仍各有一行。项目名称、类型及状态采用当前值。补交次数合并到该项目，全撤销的项目不列入；代交项目仍列出，并注明是否有个人工作量资格。已归档、已删除项目的有效交付历史保留，表格标明其可见性。

表格包含最近一次有效交付的归档文件数、首次有效交付时间、最近交付时间、有效交付次数、工作量资格、首交计数、批次与归档位置。历史已交付但首次日期未知的项目保留说明，不补造日期。有时区的时间转为北京时间，无时区的旧字符串保留原文。

“类型汇总”按当前类型统计去重项目数、具备工作量资格的项目数及纳入首交统计的项目数。合计位于筛选区域外，空表显示零。工作量资格和首交计数不等同：历史已交付标记可能保留资格，但补交不新增首次计数。

另有“任务组汇总”“任务明细”：按任务编号记录本次就绪、人工交接、待核对和原消息来源，同一项目的不同轮次可以各占一行；项目表仍按项目去重。本组导出只含所选组任务及其涉及的有效交付项目，默认打开任务明细；空任务组打开组汇总。分组过滤不会削弱全库文件保护。

数量只取该项目最近一次有效交付所对应的归档，不累加多个版本。ZIP 使用登记的分项目文件数，合包不使用整个 ZIP 总数；材料归档使用与事件路径、签名及内容清单一致的常规文件项，目录不计数。信息缺失、归属冲突或清单签名不一致时显示“待核对”，不当成零。这里展示的是历史登记事实，不表示重新扫描或验证当前磁盘文件。

导出使用同一数据库读取事务取得交付、类型、项目和归档事实，不创建表、不写类型或交付记录。类型批量调整及自动规则属于独立操作，不由点击导出触发。

保存时先生成同目录临时文件并落盘，成功后发布。默认拒绝覆盖；已有文件需要在最终路径上确认，并在后台复核文件身份。占用、取消或保存失败保留原文件。受管项目、归档目录、数据库及文件别名不能用作覆盖目标。所有用户文本按文字写入，不当作公式执行；遇到 Excel 无法保存的字符或长度会说明失败，不静默截断。

当前导出只支持本机普通目录。界面、匿名工作簿与冻结安装验收分别记录；源码功能不代表已安装版本已经更新。
