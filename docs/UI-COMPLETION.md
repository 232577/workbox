# WorkBox 次级界面落地

## 目标与依据

维护者要求继续完善整个软件，明确指出 UI 尚未落位；本轮直接延续已授权的改版，不另做网页壳或生成图冒充软件。基于 #19 的公共主题/工作台，补齐真实设置与业务对话框。只让悬浮球置顶、展开主窗保持普通层级的 #24 独立修复原样保留。

2026-11-03 查阅的官方设计参考：
- Windows 设计基础与内容布局：https://learn.microsoft.com/en-us/windows/apps/design/basics/ 和 https://learn.microsoft.com/en-us/windows/apps/design/basics/content-basics
- Carbon 数据表指南：https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines

成熟设计不只是换色：包括信息层级、导航、间距与字号、动作分组、输入/错误/空态、键盘/焦点、主题对比度、缩放与滚动、操作结果和生命周期。本轮采用共享原生对话框标题、固定操作栏和错误组件，而非为每个窗口复制一套样式。直接全盘重写会打断已验收业务；只改主题又无法解决设置难定位，因此选择增量界面适配。

## 本轮实现范围

工作设置增加分区定位、静态说明搜索、无结果反馈、未保存状态；筛选只隐藏分区，不销毁控件或保存值。搜索按 Enter 不得触发默认保存。类型管理增加本地搜索，隐藏的选中类型不能被误改名/停用。既有即时类型保存与设置显式保存仍分开说明。

统一标题/上下文/操作栏覆盖：工作设置、项目备注、项目改名、类型选择、类型管理、消息收录、首次设置、使用指南、交付确认、收录历史。材料检查及软件更新沿用已有共享标题；本轮不改变它们的业务状态。所有用户输入按纯文本显示，错误有明确文字和语义色，空错误不留空条。

不改变数据库/文件处理/交付统计、后台线程和安装协议；不改其他执行端的发布工作目录、版本号或已有发布资产。公开截图只用匿名夹具。源码集成、候选打包、本机安装和跨设备验收分别记录。

## 验收

针对实际行为先红后绿；完整原有回归保留。真实 Qt 截图检查浅/深主题、常规/窄窗口、空态/错误/筛选/长名称，固定操作区域不能跑出窗口。只读搜索/取消前后设置与项目记录相同。组件覆盖表写明已适配与遗留窗口，不以“公共主题覆盖”冒充所有业务流程重设计。

## 组件与页面覆盖清单

| 页面 / 组件 | 此增量的具体落点 | 保留的边界 |
| --- | --- | --- |
| 通用文本输入 | 原生编辑与焦点保留；浅深/禁用状态仍至少32px高 | 不改变文字、剪贴板及提交含义 |
| 搜索框 | 明确过滤用途，Enter不触发表单默认按钮 | 不自动保存或创建类型 |
| 工作设置 | 标题、搜索、四分区定位、未保存反馈、固定底部操作 | 原卡片与滚动；保存才生效 |
| 类型管理与选择 | 两个窗口的标题/错误/操作区统一；类型名称搜索与空态 | 原即时管理操作与显式分配事务分开 |
| 备注/截止日期、改名预览 | 统一上下文标题、错误与底部动作 | 取消确认、只读归档、令牌预览均保留 |
| 消息收录、收录历史 | 收件步骤层级、错误、只读历史标题与操作区 | 原拆分/确认及记录查询逻辑 |
| 首次设置、使用指南 | 统一标题与底部动作、三步说明卡片 | 引导仅最后确认保存；指南只读 |
| 交付确认 | 标题与项目上下文、固定动作区 | 默认取消、不能隐式确认交付 |
| 主工作台/文档/交付列表 | 继续沿用#19/#18组件和可调列宽；通用输入尺寸修复覆盖到这些入口 | 不改变主窗置顶或数据状态 |
| 材料检查、软件更新 | 沿用已有共享标题/状态/表格 | 不改升级交接或发布源 |

仍属后续独立体验改造的部分：复杂ZIP多项目核对流程、旧备用MainWindow流程重排，以及所有非默认系统缩放/多屏组合的完整体验。不能把这批十个对话框的适配宣称为这些工作已完成。

本增量的候选构建标识为 `v1.0.0.20261103.4`，软件版本仍为1.0.0，必须比已发布的悬浮球修复构建 `.3` 更新；标签/安装包不能覆盖旧版。源码文档中的候选标识不代表已发布或安装，实际交付以对应Release、清单和本机报告为准。源代码原生界面截图见 [实拍样例](ui/completion/README.md)。
