# WorkBox Windows 离线安装包

普通电脑选择工作站包。负责搭建办公室服务器的电脑选择办公室服务器包。两个角色各有一份完整 EXE，均可断网安装，体积分别低于 200,000,000 字节。

需要在断网环境携带两种角色时，也可以使用 `WorkBox-1.0.0-Complete-Offline-x64.exe`。它在一个文件中携带上述两份完整安装器，因此会超过 200 MB。打开后选择工作站、办公室服务器或两者。向导校验所选安装器，然后分别运行。结果页显示各项状态，若部分失败，可重新打开并仅选择尚未完成的角色。升级工作站前请先从原 WorkBox 面板退出。部署办公室服务器后，由管理员单独初始化并启动服务。

## 构建和核验

向 `python -m scripts.build_offline_combined` 传入 `--config`、`--output`、`--compiler` 和 `--chinese-messages`。JSON 中提供 `workstation` 和 `office` 两项，分别填写对应候选收据中的 `root`（EXE 路径）、`source_commit`（完整提交号）、`size`（字节数）和 `sha256`。`--output` 必须为新的构建目录。

封装按原字节储存两个 EXE，不再次压缩。构建器核对输入摘要与实际大小，编译后再复核，生成 `BUILD_INFO.json`。外壳只在自己的临时目录释放所选角色，固定摘要校验通过后才运行，记录各角色的退出码。原安装位置、登记、运行中服务及业务数据均由各角色的原安装器负责。

本机隔离验收可另制 `--isolated-validation` 版本，办公室签收项须明确标记 `isolation_trial: true` 并指向真正的服务器隔离安装器。该外壳会将工作站切换到其已有的隔离安装模式。验收版独立存放，供匿名本机验证。
