# 同名文档：新稿保留标准名称

向同一项目再次收录同名普通文档时，新稿继续使用原标准名称，旧工作副本加内容摘要后缀。例如，新稿保存为 `匿名项目_操作手册.docx`，旧稿保存为 `匿名项目_操作手册 (摘要前8位).docx`。后缀名称已占用时再加序号，不覆盖已有文件。项目名后的材料类型和扩展名均保留，不把操作手册、代码和申请表改成同一个文件名。

当前标准名文件与来源内容相同，直接复用，不增加版本。内容只与历史副本相同，仍以本次收录为当前稿；旧版已给新稿添加后缀的情况，再拖入该新稿即可按新规则收录。启动或安装不会批量改名既有文档。

来源文件留在原处。旧工作文件的编号、内容摘要、来源路径和交付事实保留，只同步其保存路径与显示文件名。既有收录日志记载的是当时的路径，不改写历史。项目文件列表展示实际的新稿和旧稿，ZIP 及历史材料归档使用原有规则。

文件夹收录按原相对目录处理，同名但位于不同子目录的文件各自管理。直接从本项目工作目录拖入的文件只登记或复用，不移动这个来源文件。目标同名文件未登记、内容与登记不符、被占用或路径含重解析点时，停止该次收录并提示核对，保留现场，不改为给新稿加后缀。

轮换使用固定文件身份的句柄、数据库事务和持久恢复记录。复制、取消或提交失败时恢复原标准名；意外退出后，未提交操作回滚，已提交操作只核验。无法确认文件身份或恢复记录损坏时暂停存储写入，读取界面仍可用。复制完成但恢复记录尚未写入时退出，可能保留 `~$workbox-编号.stage` 暂存副本；它不进入文档列表和材料交付清单，不自动删除身份不明的文件。

验证使用匿名夹具，覆盖普通文件和文件夹入口、旧版布局、连续版本、恢复旧内容、同内容重复、取消与故障回滚、进程强退重启、文件占用与路径保护，以及交付历史和归档保持。正式包和实际安装结果另按发布记录核验，源码修改本身不代表已发布。
