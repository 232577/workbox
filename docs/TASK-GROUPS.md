# 历史任务记录兼容

当前桌面已按用户选择回到原项目状态工作流，独立任务组页面、手工交接及任务维护入口退役。普通文字收件不再建立新的任务组；项目列表通过只读收件批次色号识别同批项目，详见[项目批次标记](PROJECT-BATCH-MARKERS.md)。

已有任务组、任务号、原消息、材料关联及交接动作记录继续保留，不删除、不补造、不重放合并。历史G编号仍是原编号。任务曾移组时，批次标记读取当前归属；同一项目的多批关系保留，不用改名、复制项目或移动目录来实现。

原任务后端保留兼容，已有材料绑定仍指向确切交付事件及其修正版本；历史交接不等于网络发送，也不作为当前项目状态或新增工作量的依据。旧交付被撤销/恢复时，历史解释沿用原有效性规则，不自动伪造已发送事实。

全部交付表仍按canonical项目去重。原“任务组汇总”和“任务明细”工作表作为已有记录的历史附表保留；新日常操作使用项目的待开发、开发中、待交付和已交付状态，不再通过任务组界面确认交接。项目表另含当前可核实的收件批次编号。

升级不改变原项目ID、batch_id、物理工作目录、文件名、交付事件、项目类型及配置。旧内部任务编号格式的文字需先核对项目名称，不能把编号误当项目名创建新目录。
