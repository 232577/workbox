# 项目工作台与控件改版

本轮以“找到项目 → 查看实际文件 → 处理当前项目”为主路径，保留原四状态、项目排序、同批进度与既有文件和交付规则。

## 设计依据

- [Linear 2026 界面更新](https://linear.app/now/behind-the-latest-design-refresh)：稳定的标题与动作位置，减少导航干扰。
- [Microsoft 列表与详情](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/list-details)：根据可用空间组织并排与单页详情。
- [IBM Carbon 数据表](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines)：列表工具、表头和正文密度保持一致。

采用这些交互原则，继续使用原生 PySide6、锁定的 QFluentWidgets 与 Qt 菜单，不改变应用技术栈。

## 当前界面规则

项目页将搜索、状态、批次和附加筛选集中在清单内。附加条件直接显示，并可单独清除。ZIP 页复用同一查询输入并放在该页标题旁；切页保留查询。

选择「待开发」时，清单标题旁提供「导出名单」，将全部未归档、未删除的待开发项目名称保存为 Excel 工作簿。搜索、批次及附加筛选只影响界面中的清单。工作簿只有「项目名称」一列，没有项目时仍保留表头。

当前项目集中展示完整名称、状态、类型与批次标识。“打开工作目录”直接可见；符合条件的待交付项目提供“确认交付”，仍进入原有版本选择与确认流程。类型修改放在项目菜单，批量选择时继续提供批量修改入口。

工作区宽度不足 800 个 Qt 逻辑像素时使用单页清单或详情。点击项目或键盘激活进入详情，“返回项目清单”恢复阅读位置。宽窗口恢复并排和人工拖动的分栏比例。窗口自适应是同一工作流，不新增布局模式。

文件区的标题、数量和动作在表头上方。文件名使用常规字重，数字右对齐，长名称完整换行。列宽、选择、滚动与后台读取生命周期沿用原机制。

交付页明确展示“全部日期”或选定日期，支持直接返回日期选择。主表优先获得空间，详情可以收起、展开和拖动；保留人工设置及窄窗口标签切换。全量导出入口标注“导出全部”，筛选不改变导出范围和不可变交付历史。

## 控件规则

统一使用可用的中文无衬线字体，普通正文 14px、辅助文字 12px。标题按内容层级设置字重，窗口放大不放大字体。浅深主题沿用 WorkBox 青绿色强调色；主动作、普通动作、禁用、悬停、按下和键盘焦点有独立反馈。

日期仍是 Qt 原生日历与分段编辑，扩大末端下拉按钮命中范围；月份导航、选中和周末样式适配浅深主题。输入框、组合框、数字步进与复选框使用统一间距和可访问名称，非法完整日期继续保留供用户修正。

## 协作与验证边界

本轮从含批次交付进度的 main 开始，项目批次查询和业务存储规则保持。公共控件、项目工作区、文件视图和交付页分别实现后统一检查，避免各页面独立覆盖同一套样式。

验证使用匿名隔离数据，包括 110 个项目、长中文名称、不同状态与文件。实际 Qt 截图用于视觉核对；自动回归覆盖清除筛选、窄窗返回、列宽和分栏恢复、直接操作保护、日期及详情展开。具体结果与限制见仓库 VERIFICATION.md，截图以对应源码散列标识。

源码合入 main 不代表正式安装包已发布。发布端须从准确 main 构建、核验新安装包，再同步稳定更新清单；本轮不改写历史版本标签或真实用户数据库。
