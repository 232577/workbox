# 工作箱界面精简与归档分类修正

## 已确定的范围

沿用维护者先前选择：精简主界面，低频功能移到高级入口；保留原项目状态、排序、同批色号以及全部交付表导出。新增明确规则：单个项目最近有效交付归档恰好16件为可运行，其他已知数量为生成材料；未知事实不当作0。ZIP自动交付的文件门槛是另一项规则，本轮不改。

这轮采用现有PySide6、锁定QFluentWidgets、原生菜单和滚动，不重写主题、字号、选择或文件收录服务，不新增简洁/完整两种模式。只读检查确认旧分类条件为至少4件，导出显示项目当前类型，导出本身不写库。

## 页面安排

- 项目页只留一个结果计数。名称、状态、类型和批次保留，省去无意义的ZIP 0；批次筛选保持直接可达，归档范围、日期、类型、加急收进可展开的筛选区。收起后有生效条件标识和清除入口，收起不清条件。多选及批量操作保留原目标语义。
- 文档区只留一处选中项目标题与项目操作；无选择时不显示无用按钮和重复空白表头。无文件/读取失败保留明确提示；有文件后保留双击打开，其他目录和刷新操作集中到原生菜单，失败时直接重试。项目类型修改仍清楚可达。
- 交付页保留日期、搜索、全量导出、合计及必要分类计数；低频筛选与更正按钮集中到现有菜单。选择、原因草稿、取消、失败重试与撤销/代交的不同语义保持。窄窗继续优先显示记录。
- ZIP页按当前对象突出关联或核对合包，普通版本定位、可用标记和维护操作归入菜单。正常监视说明不常驻占空间，异常、等待和不可读提醒不可隐藏。
- 待核对页隐藏实际无筛选作用的共享搜索，保留原文、原因、双击核对和精确反馈定位。空态用一句说明。
- 去掉重复品牌说明、页脚教程，保留忙碌取消、后台运行和退出及必要工具提示。成功提示不永久占据整行；错误、待核对和忙碌提示需持续可达。

## 分类兼容与数据边界

分类策略增加比较方式exact/at_least。旧库迁移仅增字段，旧阈值、开关、类型、事件水位及版本号保持；旧配置默认at_least。新库预设exact/16但未来自动分类仍默认关闭。显式旧式API调用保持原至少数量含义，新UI明确传比较方式。预览、批量应用、未来交付使用同一判定；比较方式进入令牌和新审计事实，历史审计不改。

当前维护者这台设备在验证及恢复点就绪后，显式改为exact/16，并用既有预览/确认/追加审计/撤销链纠正旧规则结果。只处理即时预览中已核实、当前仍为旧规则结果且没有之后人工选择的项目，写入前核对明确ID集合；不得通过安装或导出静默回填，也不新增绕过手工保护的通用修复入口。

当前设备的只读盘点及候选名单仅保存在私有验证目录，正式操作前重新核查，不能把旧数字当写入许可。文件、目录、交付事件/更正、工作量资格和历史记录保持；仅明确的策略与分类审计允许变化。其他使用者旧配置不自动改成维护者规则。

## 共用控件与验证

主题/字体沿theme.py与control_styles.py；按钮/输入沿ui_components.py；选择、列表、表格和滚动沿fluent_views.py；反馈沿原notice/bubble；日期沿现有DateEdit；类型由数据库与分类服务承担。原生QMenu/QWidget展开区不另建控件系统。信息可通过文字、编号、键盘与工具提示读取，不能只有颜色。

覆盖浅深、660窄窗、长项目名、多批、活动筛选可见与清除、选中与滚动保持、错误/取消/忙碌、无文件/无记录/无搜索结果。分类覆盖0/5/15/16/17/未知、单项目和合包、补交、撤销恢复、旧配置迁移、同值手工选择保护、导出只读。测试全部匿名；正式数据仅只读盘点和有恢复点的明确分类纠正。
