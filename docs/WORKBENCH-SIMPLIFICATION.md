# 日常工作台精简

本文件记录上一阶段设计。用户随后选择原项目状态与批次色号，独立任务组页面及交接维护入口退役；当前规范以[项目批次标记](PROJECT-BATCH-MARKERS.md)为准。

用户选择保留日常主流程，将低频功能移到高级设置。本轮调整入口层级，项目、文件、交付、任务及配置的业务规则沿用现有实现。

## 取舍

考虑了删除低频功能、增加简洁/完整两套模式，以及统一精简入口。采用统一精简入口：避免两套布局和设置状态，已有维护与恢复功能仍可找到。具体入口分组依据功能职责，不声称有使用频率遥测。

## 主界面

- 侧栏常驻任务组、项目、今日工作量；底部保留一个“高级设置”入口。
- 待核对数量大于零时显示直接入口与数量；正在查看待核对页时也保留入口，清空后离开才收起。高级设置中始终可打开待核对页，收件反馈仍定位准确条目。
- ZIP库通常收进高级设置；存在待核对合包或归档错误时，恢复直接入口和数量，正在查看ZIP页时也保留。异常提醒不受项目搜索或筛选影响，浅深色和窄窗均可辨认。
- 顶部保留粘贴消息、收进文件。底部保留后台运行、退出及处理时的取消，帮助和更新移到高级设置。
- 沿用原有项目筛选、文档区、项目类型修改和上下文操作，不在此轮重排数据区。
- 材料检查和收录记录不再占据项目内容栏按钮位置；材料检查仍在所选项目操作菜单，收录记录在高级设置。

## 高级设置

使用已有原生 Qt 菜单，分组提供工作设置（含项目类型词典）、归档分类、ZIP归档库、待核对、收录记录、监视详情、历史消息补录、外观、使用指南和检查更新。复用原回调、保存/取消和忙碌保护，不重新实现业务服务。查看 ZIP 时页标题明确，常用页面仍可直接返回。

## 任务组

四个主要动作是新建任务组、添加消息、记录已交接、导出本组表格，另保留一个“更多”入口。复制本组未交、查看项目文件、新一轮、撤销交接、关联交付记录和核对本组消息保留当前组上下文；撤回、重开、移动、改组名/颜色及跨组复制集中到更多里的“高级任务操作”。历史补录与归档分类改由全局高级设置进入。

切页不丢失选中任务、筛选、滚动位置或未保存输入；导出仍按所选组，交接仍核对所选任务及确切关联版本。未选择、处理中、取消和失败均沿用现有说明与保护。

## 验收

检查常驻入口减少而所有旧功能仍可达；待核对从零到有再到零；菜单键盘操作、当前选择与忙碌禁用；660px窄窗及浅深色，完整长名和滚动锚点；保存/取消、导出、后台运行和退出。自动测试只用匿名夹具和offscreen。正式更新沿用已有备份、准确main构建与同包验证，新标签和资产不覆盖旧版。
