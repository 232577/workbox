# WorkBox 官网设计

## 方向与范围

面向在 Windows 上接收项目、整理文件并反复交付的个人。首页帮助访客理解用途并下载；独立的指南和版本页服务阅读与查找。文案使用中文，直接描述可验证的能力，不编造用户评价、使用量或验收结论。

品牌保留深蓝文字与青绿操作色，以留白和字级组织内容。真实窗口直接展示，不再加深色展示台、假浏览器框或装饰性流程图。首页只用一张产品实拍，不为凑图加入无关图片；不添加滚动表演、背景光晕和卡片嵌套。产品事实用段落与少量分隔线组织，完整操作示例留在指南。

本文件仅管理官网。桌面设计体系与 `.impeccable/design.json` 独立，官网配色不反向修改桌面应用。

## 页面结构

1. **首页 `/`**：居中标题“项目归位，交付有数。”、短说明、一个主下载按钮；平台与本机数据说明紧随操作。`#actual-ui` 直接显示真实项目工作台，图注标明 r4 示例构建，来源详情链接到指南。
2. **三项价值 `#overview`**：材料按项目归位、当前文件与旧稿分开、整批待完成数量清楚。桌面三列、手机纵排，不用卡片容器；仅一处指南入口。
3. **下载 `#download`**：当前安装包、GitHub 备用、平台与安装提示；文件名和 SHA-256 按需展开，历史版本移出首页。
4. **指南 `/guide.html`**：可定位的目录、安装与恢复、固定匿名演示、历史视频、悬浮收件、四步流程、日常工作台、批次与规则、FAQ、媒体来源。章节直接可读，仅补充说明使用折叠。
5. **版本 `/releases.html`**：当前包与来源、更新和工作规则、30 个历史安装包、明确标注的历史任务组说明。下载路径和校验身份保持。
6. **共享导航与页脚**：页首仅标志、指南、版本和下载；外观选择移到页脚，与源码、许可、所有者统计和匿名统计说明并列；赞助保持关闭。

## 视觉与样式所有权

`public/release-page.css` 最后加载，只在 `.home-page` 范围定义首页最终视觉。`styles.css` 提供基础字体与共享控件，`homepage.css` 保留结构及流程图基础，`theme.css` 提供共用主题和焦点色。首页最终颜色由 `--release-*` 管理并映射至既有 `--wb-*`；不把首页 token 复制到统计页。

使用系统无衬线与等宽字体，不请求外部字体。正文 16px，功能与辅助文字至少 13px；控件圆角 8px。首页最大 1040px、实拍最大 840px、指南阅读列最大 920px；主标题 38–64px。760px 以下价值、下载和指南双栏纵排，420px 以下页边距 16px，页首下载文字隐藏但主下载按钮保留。优先显示完整窗口而非裁切截图。

## 交互与可访问性

- 指南与版本页直接显示主要章节，校验值、媒体补充、FAQ 和历史功能使用原生 `details/summary`。无脚本时仍可读取完整内容，下载与原图链接正常可用。
- `homepage.js` 在直接打开 hash、hashchange 和点击同页锚点时展开目标的全部折叠祖先。目标位于隐藏的工作流程面板时，先选择对应 tab，再定位；同一 hash 再次点击仍可重新展开。首页旧锚点按固定同源白名单转到指南或版本页，已有首页目标优先；无脚本时可经导航进入对应页面。编码 hash 可用，非法编码与不存在的目标安全忽略。
- 四步流程仅在四块面板完整时增强为 tabs。保留左右方向键、Home/End、焦点和可访问状态；未增强时四块正文全部可读。
- 示例用原生按钮、`aria-pressed` 与 live status；增强成功才显示操作，重复演示不累计工作量。没有文件选择、真实文件处理、上传、存储或网络请求。
- 主题选择为有标签的原生 select。`theme.js` 在样式前初始化网站偏好，支持跟随系统、浅色与深色；只保存 `workbox-site-theme`，与桌面软件独立。存储不可用仍可切换；无脚本通过系统深色样式回退。
- 保留跳到主要内容、可见焦点和原生键盘操作。按钮与主要 summary 通常至少 44px 高；减少动画与系统强制色有对应样式。校验值可直接选择，复制成功或失败通过状态区域反馈。

## 媒体、发布与业务事实

下载目录对应 **WorkBox 工作箱 1.0.0 正式安装版**，构建 `v1.0.0.20261112.2`，来源提交 `8295ee8e5a37958b7a58c18a9c22a970b85ec31a`。文件为 `WorkBox-1.0.0-Setup-x64-20261112-r2.exe`，42,280,123 字节；SHA-256 为 `719baaa47e3ba7feeb29d0574565785a15880a03242ba5a9ac1e86832837ec23`。下载身份以 `worker.mjs` 的目录为准，保留当前及全部 30 个历史下载路由，不公开未发布的 11月9日 r3 或 11月10日 r1/r2/r3/r4。本次批量选择后，可在已选项目的右键菜单中统一“标记加急”或“取消加急”。菜单显示所选数量，操作对象固定为打开菜单时的选择；混合加急状态也可一次统一设置。单选和右击未选项目仍只处理当前项目，多选菜单的其他操作继续只作用于“当前项目”。文字项目列表支持 APP 名称；已登记项目的文件、ZIP 和目录可带下划线后的任意附注，完整项目名优先。匹配统一项目名末尾 APP 前的空白和大小写，保留原显示名、编号和工作目录。新项目名称不会按任意附注自动裁剪；历史同名编号、已归档或已删除项目仍需核对，不自动合并。保留 Studio 与名单核对，恢复窗口位置与最大化状态，保持模态窗口优先和悬浮入口可用。全局快捷键默认关闭，可在工作设置中启用。保留四项修复：批量选择项目时减少重复读取；ZIP 或待核对信息读取失败后清单与详情保持同步，不可用详情清空并保留重试提示；项目搜索最多 1000 个字符；退出时保存设置或升级时备份数据库失败后，已启用的全局快捷键仍可使用。下载目录发布须以对应资产可公开下载和同一构建的安装、原生交互验收为前提。

主图 `workbox-pending-export-light-20261109-r4.png`（1102×792）与窄窗对照 `workbox-pending-export-narrow-dark-20261109-r4.png`（662×512）来自同一 r4 隔离实例，来源提交 `2432b7e237db6424bd70e01f9a96f7567c5e644e`。两图保留原始 PNG、尺寸和原图链接，不能改称 r7 实拍；r7 的数量与日期规则通过正文说明。主图直接加载，无脚本也能显示；脚本检测到失败时显示文字说明及指南入口，不用假图冒充界面。`MEDIA.json` 登记的 58 项媒体保留原字节及各自构建来源。

44 秒视频明确为 2026-10-30 构建的历史截图步骤演示，带无声字幕，不冒充连续录屏或当前构建。保留原生 controls、字幕、poster 和视频备用链接，不自动播放。

页面压缩可见层级，不删去关键边界：主动收件、不读微信或监控剪贴板、复制并保留原件；通用模式人工确认交付；待完成只计待开发和开发中，显示零与总数；首次有效交付、补交、排除个人工作量与撤销分别说明。待开发名单导出保留全量范围与单列工作簿解释。归档分类“恰好 16 个文件”与 ZIP 自动交付的每项目 4 个实际文件门槛分开，未知数量不推定为零。历史任务组保持历史标记，不作为当前操作入口。

安装提示明确未商业代码签名、平台限制和升级恢复办法。备份与迁移包括 data、工作目录、归档目录及全部已登记历史文稿目录（可能仍在原工作位置），迁移后核验路径与历史文件；旧版更新失败时按原目录恢复，不引导卸载或删除 data。下载开始不代表下载完成或安装成功。网站重排不表示产生新的桌面安装包，也不证明已上线。

## 隐私与所有者统计

公开首页无需账号，官网不接收项目文件、不提供自动云同步。匿名浏览、站内下载开始与 GitHub 备用链接点击沿用原统计路径并在页脚披露；备用点击不冒称下载。`support.json` 保持 `{ "enabled": false, "methods": [] }`，隐藏赞助入口。

`/stats/` 是独立的所有者工具，布局与 `stats.css` 不受首页重排影响，只共享网站主题偏好。保留私密登录、服务器会话、API 权限和无预填数字的数据容器。统计日期按北京时间；下载计成功开始传输并去重续传，历史不补造；读取错误可重试，不能把失败冒称零值。密码不进入 URL 或持久化浏览器存储。许可链接保持可达，技术实现清单不混入产品文案。
