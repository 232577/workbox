# WorkBox 官网设计

## 方向与范围

面向在 Windows 上接收项目、整理文件并反复交付的个人。首页先回答用途、实际界面与下载，再让需要操作细节的人展开指南。文案使用中文，直接描述可验证的能力，不编造用户评价、使用量或验收结论。

品牌以 navy 深蓝和青绿呈现。真实窗口置于带箱形凹口的深蓝展示台，呼应工作箱标志；不加假浏览器框，不用装饰性渐变、悬浮卡片堆叠或大量胶囊标签。产品事实用分隔线和横向内容行组织，明确区分软件截图、流程示意与可操作示例。

本文件仅管理官网。桌面设计体系与 `.impeccable/design.json` 独立，官网配色不反向修改桌面应用。

## 页面结构

1. **首屏**：左侧“项目归位。交付有数。”、短说明、正式安装版下载和流程体验入口；平台与本机数据说明紧随操作。右侧 `#actual-ui` 显示真实项目工作台。窄窗深色对照与图片构建来源各自使用原生折叠。
2. **三项价值 `#overview`**：材料按项目归位、当前文件与旧稿分开、整批待完成数量清楚。使用三行事实与通往指南的链接，避免展开完整操作手册。
3. **独立体验 `#try-workbox`**：`#workbox-demo` 保留固定匿名项目示例，依次呈现复制材料、保留版本、人工交付；不占据首屏产品截图的位置。
4. **下载 `#download`**：提供当前正式安装包、GitHub 备用、兼容性、文件大小及安装注意事项。“当前版本与工作规则”、历史版本、SHA-256 校验值分别按需展开。
5. **默认折叠的指南 `#guide`**：完整保留历史步骤视频、悬浮收件、四步工作流程、详细能力、日常工作台、项目批次、工作规则、FAQ 与历史任务组说明。原有 section ID 和下载地址继续可达。
6. **页脚**：源码、版本记录、GPL 与第三方许可、所有者统计入口和匿名统计说明；赞助保持关闭。

## 视觉与样式所有权

`public/release-page.css` 最后加载，只在 `.home-page` 范围定义首页最终视觉。`styles.css` 提供基础字体与共享控件，`homepage.css` 保留结构及流程图基础，`theme.css` 提供共用主题和焦点色。首页最终颜色由 `--release-*` 管理并映射至既有 `--wb-*`；不把首页 token 复制到统计页。

使用系统无衬线与等宽字体，不请求外部字体。正文以 16px 和宽松行距阅读，标题依层级缩放；控件圆角 8px，展示台与示例边界 12px。桌面内容最大 1320px，左右留白 40px，首屏列宽比例为 0.72:1.28，主标题 60–76px。960px 以下首屏纵排，700px 以下价值与体验纵排、下载单栏，手机标题 48–64px；370px 以下进一步收紧边距。优先显示完整窗口而非裁切截图。

## 交互与可访问性

- 指南、媒体说明、发布规则、历史下载和 FAQ 使用原生 `details/summary`。无脚本时仍可手动展开并读取完整内容，下载与原图链接正常可用。
- `homepage.js` 在直接打开 hash、hashchange 和点击同页锚点时展开目标的全部折叠祖先。目标位于隐藏的工作流程面板时，先选择对应 tab，再定位；同一 hash 再次点击仍可重新展开。编码 hash 可用，非法编码与不存在的目标安全忽略。
- 四步流程仅在四块面板完整时增强为 tabs。保留左右方向键、Home/End、焦点和可访问状态；未增强时四块正文全部可读。
- 示例用原生按钮、`aria-pressed` 与 live status；增强成功才显示操作，重复演示不累计工作量。没有文件选择、真实文件处理、上传、存储或网络请求。
- 主题选择为有标签的原生 select。`theme.js` 在样式前初始化网站偏好，支持跟随系统、浅色与深色；只保存 `workbox-site-theme`，与桌面软件独立。存储不可用仍可切换；无脚本通过系统深色样式回退。
- 保留跳到主要内容、可见焦点和原生键盘操作。按钮与主要 summary 通常至少 44px 高；减少动画与系统强制色有对应样式。校验值可直接选择，复制成功或失败通过状态区域反馈。

主图 `workbox-pending-export-light-20261109-r4.png`（1102×792）与窄窗对照 `workbox-pending-export-narrow-dark-20261109-r4.png`（662×512）来自同一 r4 隔离实例，来源提交 `2432b7e237db6424bd70e01f9a96f7567c5e644e`。两图保留原始 PNG、尺寸和原图链接，不能改称 r7 实拍；r7 的数量与日期规则通过正文说明。主图加载成功才替换流程图，失败或禁用脚本时保留明确标注的流程后备。`MEDIA.json` 登记的 58 项媒体保留原字节及各自构建来源。

44 秒视频明确为 2026-10-30 构建的历史截图步骤演示，带无声字幕，不冒充连续录屏或当前构建。保留原生 controls、字幕、poster 和视频备用链接，不自动播放。

页面压缩可见层级，不删去关键边界：主动收件、不读微信或监控剪贴板、复制并保留原件；通用模式人工确认交付；待完成只计待开发和开发中，显示零与总数；首次有效交付、补交、排除个人工作量与撤销分别说明。待开发名单导出保留全量范围与单列工作簿解释。归档分类“恰好 16 个文件”与 ZIP 自动交付的每项目 4 个实际文件门槛分开，未知数量不推定为零。历史任务组保持历史标记，不作为当前操作入口。

安装提示明确未商业代码签名、平台限制和升级恢复办法。备份与迁移包括 data、工作目录、归档目录及全部已登记历史文稿目录（可能仍在原工作位置），迁移后核验路径与历史文件；旧版更新失败时按原目录恢复，不引导卸载或删除 data。下载开始不代表下载完成或安装成功。网站重排不表示产生新的桌面安装包，也不证明已上线。

## 隐私与所有者统计

公开首页无需账号，官网不接收项目文件、不提供自动云同步。匿名浏览、站内下载开始与 GitHub 备用链接点击沿用原统计路径并在页脚披露；备用点击不冒称下载。`support.json` 保持 `{ "enabled": false, "methods": [] }`，隐藏赞助入口。

`/stats/` 是独立的所有者工具，布局与 `stats.css` 不受首页重排影响，只共享网站主题偏好。保留私密登录、服务器会话、API 权限和无预填数字的数据容器。统计日期按北京时间；下载计成功开始传输并去重续传，历史不补造；读取错误可重试，不能把失败冒称零值。密码不进入 URL 或持久化浏览器存储。许可链接保持可达，技术实现清单不混入产品文案。
