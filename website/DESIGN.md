# WorkBox 下载页设计记录

## Overview

### Creative North Star

把下载页做成一张清楚的桌面工作台：先说明悬浮球收件与下载，再解释材料去向。浅灰或深灰底承托内容表面，青绿只强调操作和规则。保留文件夹流程图作为没有真实软件截图时的后备内容。

### Product context

- Audience and primary job: 使用 Windows 的个人项目管理者；了解用途、确认兼容性并下载安装包。
- Locale: zh-CN；公开日期与版本按发布目录；首页改版于 2026-10-28。
- Register: 直接说明能做什么，不编造使用量、评价或性能。
- Canonical owner: public/styles.css 管理基础字体与既有公共色，保持不变。public/homepage.css 管理首页原有结构；public/theme.css 的 --site-* 是官网浅深主题唯一颜色源，映射到首页 --wb-* 及 stats.css 的 .stats-page 语义变量。首页与所有者统计页引入同一主题文件和原生外观选择，共享网站偏好；桌面应用的主题偏好独立保存。
- Scope: 公开首页无需登录，不请求外部字体，不依赖框架。匿名站点计数沿用同域 /api/events；统计页单独登录。

## Colors

浅色底为 #F3F5F5，内容表面 #FFFFFF，文字 #192B32，次文字 #455B64，操作 #086D60；深色底为 #1C2023，内容表面 #282D30，文字 #EDF4F5，次文字 #B8C8CE，操作 #83DCC7。层级来自表面差、边界和克制阴影。主要按钮以对比文字呈现；焦点为3px轮廓，浅色 #005FCC，深色 #89CAFF。状态同时写明含义。

## Typography

标题用系统 Segoe UI Variable Display / 微软雅黑，正文用系统无衬线；代码和安装包信息使用等宽字体。不请求网络字体，避免加载位移。

## Layout

首屏直接说明项目、交付和悬浮球，保留下载、视频与使用说明入口；其下优先使用隔离匿名实例的真实桌面截图。截图未提供时显示有明确标签的文件夹流程图，不冒充软件截图。首次使用推荐通用模式的说明紧接主要操作。下载区采用稳定的深色背景，其他区域随网站主题变化。

真实截图接入后，首屏文字在桌面横向分成标题与操作说明两组，完整软件界面放在下一行，最大1120px宽，保留原生窗口本身，不添加假浏览器边框。截图区域按1120:760预留比例，窄屏至少240px；图片完整包含在区域内，可点击链接打开原图放大。图注为“实际界面 · 示例资料”。浅深图片独立确认加载成功后才显示，选择与网站解析出的外观一致；加载中、失败或禁用脚本时使用原有文件夹流程图。可见层的替换不改变预留尺寸，不显示破图图标，也不先闪现另一种外观。

其后为四步流程切换、六项项目管理能力、五项默认工作规则、下载与校验、常见问题。流程以真实顺序编号，但四种项目状态不是强制线性流转。850px 以下首屏与流程纵排，560px 以下功能列表单列；320px 宽保持内容可读，无横向页面溢出。页面自然滚动，页头固定且锚点与键盘焦点留出空间。

主题路径为 theme.css 的 --site-canvas/surface/layer/ink/muted/accent/line/focus → .home-page 的 --wb-* 兼容变量 → 组件。旧 homepage.css 的默认色由该适配层统一覆盖；不把这套值复制进 styles.css。系统字体继承公共 token；正文14–16px，关键标题27–58px，辅助说明至少12px（流程图内次要注释允许11px），完整规则在正文重复可读。控件圆角8px，主要内容表面12–16px。

## Components

- 主要按钮均为下载链接，使用相同名称和目标。
- GitHub 备用下载、源码、版本记录为普通链接。
- FAQ 使用原生 details / summary，支持键盘和触摸。
- 网站外观使用有标签的原生 select，提供跟随系统、浅色、深色；默认跟随系统。theme.js 在首个样式表前同步读取 workbox-site-theme，实际控制在文档就绪后启用。只保存此项网站外观偏好，不宣称与桌面软件同步；存储被禁止时本页照常切换，无有效值则跟随系统。系统变化只影响跟随系统选项。无脚本时隐藏失效控件，由 CSS 系统主题继续展示完整内容。
- 原生select弹出菜单归操作系统管理，不自行绘制。主要操作、导航、选择器、FAQ标题和校验复制按钮至少40px高；明显焦点环不依赖颜色渐变。
- 工作流程使用原生 button 渐进增强为 tabs，左右方向键环绕，Home/End 到首尾；选择状态、焦点与关联面板同步。无脚本或面板缺失时不启用控件，四块正文全部可读。不得用自动轮播隐藏说明。
- 工作设置是默认值说明，采用 dl，不使用不能操作的开关或输入框；需在桌面软件修改。
- 悬浮收件说明在独立 `#floating-inbox` 区域，用真实动作名称说明拖入对象、球的交互、反馈定位和后台/退出边界。窄屏按材料、球、反馈的顺序单列阅读。截图视频只使用隔离实例的真实窗口，并明确局部放大，不冒充连续拖动录像。
- 复制校验值使用原生 button；成功和权限失败通过固定高度 aria-live 状态区域告知，不移动按钮。不支持剪贴板时保留可选中的完整哈希。
- 所有链接、按钮和 summary 有可见焦点、hover 与 active 反馈；不使用浏览器弹窗。
- 公开首页无业务表单或 CRUD；下载结果由浏览器原生下载管理，不声称网页已确认下载成功。

## Content and data boundaries

固定版本 1.0.0、发布日期、大小和 SHA-256 以主代理给定的已验证安装包为准。公众可下载；干净安装不含业务数据。兼容性、未商业签名说明与升级备份要求明确呈现。工作流程说明保留主动收件、不读微信、保留源文件、首次有效交付统计、撤销退回待交付的边界。不使用客户资料或真实名字。

## Do's and Don'ts

品牌标志为深蓝底的折叠盒/W矢量，复用桌面端 `branding.py` 的同源图形。
底色 `#102D40`，青绿色折盖 `#8AE7DA/#4DCAB9`，盒身 `#53D6C2/#25B5A4`。
官网、统计页及浏览器favicon统一使用此标志，保留统计访问边界。

- Do: 首屏突出下载，完整呈现兼容性与备用来源。
- Do: 清楚区分流程示意与应用截图。
- Don't: 编造用户数、下载量、测评或集成。
- Don't: 把复制失败隐藏，或引导用户关闭系统安全防护。

## 所有者统计页

`/stats/` 为所有者统计入口，属于管理工具。公开下载页仍沿用前述营销布局；此页增加登录、读取和会话恢复状态，原有“无登录、无需会话”的描述仅适用于公开下载页。

- 基础字体继续由 `public/styles.css` 管理；`public/stats.css` 只在 `.stats-page` 范围把共享 `theme.css` 的 --site-* 映射到既有 --ink/--canvas/--soft/--muted/--line/--ocean。首页与统计页使用同一外观选择和网站偏好。今日及浏览曲线使用青绿，累计及下载虚线使用蓝色（浅色 #236B9A，深色 #91CAFF）；图例同时标明实线、虚线，文字不依赖颜色表达含义。
- 主体按今日／累计摘要、每日趋势、每日明细和统计口径排列。趋势实线／虚线同时区分数据系列，明细表保留完整日期和数值。窄屏摘要纵向排列，趋势图保留900px宽度使标签维持可读字号；趋势图和明细分别提供原生横向滚动、键盘焦点和可见提示，页面本身不横向溢出。
- 原生 HTML 表单、按钮和操作系统下拉菜单为本页控件所有者，无依赖框架。密码默认遮罩、允许粘贴和密码管理器，提供显示／隐藏按钮；不进入 URL 或持久化浏览器存储。认证依赖服务器会话，静态 HTML 不含统计值。
- 读取失败显示错误及重试，首次错误不显示虚构零值；已有数据刷新失败时保留上次数据并明确时间。401 清空当前数据并返回登录；退出失败保留重试入口，不声称已退出。请求设超时并防止失效响应覆盖新状态。
- 日期按服务器返回的 Asia/Shanghai 日历日显示，更新时间明确为北京时间。CSV 只导出当前已取得的每日数据。下载表示成功开始传输，续传去重，不代表下载完成或安装；GitHub 备用仅计点击并另列；启用前历史不补造。

本轮仅修改统计页HTML与样式，不改变stats.js、认证、API、数据容器ID或统计读取流程。独立浏览器以本机网络拦截返回401核对登录；仪表盘、图表、表格、读取失败保留数据、重试和CSV使用明确标记的隔离测试数据，既未读取真实统计，也未把构造数字写入公开页面。1280与320宽度均核对浅深外观、显示密码、登录入口、范围选择和CSV可达。相关截图均标注“隔离视觉测试数据 · 仅本机，不发布”。

首页页脚保留低调的“第三方许可”链接，指向公开仓库THIRD_PARTY_NOTICES.md；实现技术与许可清单不混入功能文案。
