安装与升级

目标平台为 Windows 10 1809+ / Windows 11 x64；实际验收范围以对应发布记录为准。暂不支持 macOS、ARM 和 32 位系统。安装包不包含已有项目，首次使用自动建立数据目录。安装包未做商业代码签名，请通过官网下载区获取并核对校验值。

升级前请备份 data、工作和归档目录及全部已登记历史文稿目录（可能仍在原工作位置）。迁移后核验路径与历史文件可读性。新电脑不会自动同步旧电脑的项目数据。

新版怎样在线更新？从窗口底部或“高级设置 → 检查更新”主动检查一次。有新版时点击“更新并重启”。WorkBox 会下载并校验安装包、备份数据库，在原目录安装成功后重新打开。

旧版本只退出，没有更新？先备份数据，确认工作箱已退出，再运行官网下载区经过校验的新安装包，选择原安装目录。不要卸载，不要删除 data 或重建项目。安装后可在主窗口标题核对构建号。

查看项目批次用法
待核对和 ZIP 提醒，会不会被收起来？

待核对数量大于零时，顶部导航显示入口和数量。正在查看待核对页时也保留，清空后离开才收起。ZIP归档库通常从高级设置进入，有待核对合包或归档错误时会在顶部导航显示，正在查看 ZIP 页时也保留。ZIP 异常提醒不受项目搜索或筛选影响。高级设置中始终可以打开这两个页面。

设置、检查和维护工具，在哪里打开？

“高级设置”集中提供工作设置（含项目类型词典）、归档分类、ZIP归档库、待核对、收录记录、监视详情、外观、使用指南和检查更新。材料检查仍在所选项目的操作菜单。顶部保留粘贴消息、收进文件；底部保留后台运行、退出，处理中可取消。

项目筛选和操作在哪里？

搜索和“筛选”在清单上方，状态、批次和多选位于项目清单。首次新增日期下拉位于批次下方，常驻显示。点击“筛选”展开筛选区，可按归档范围、截止日期、类型或加急查找。收起后仍显示生效条件，可逐项清除。

宽窗并排显示清单和详情。窄窗点击项目打开详情，再点“返回项目清单”回到原阅读位置。选中项目后可直接打开工作目录，符合条件时也可从项目操作确认交付。

粘贴消息后可定位本次项目，包括沿用的同名项目。已有项目保留原状态和目录。

怎样统一标记或取消多个项目的加急？

开启“批量选择”，选好项目，在其中一个已选项目上右击。在“所选 N 个项目”区域选择“标记加急”或“取消加急”，会统一应用到打开菜单时的选择。单选和右击未选项目仍只处理当前项目；“当前项目”区域的其他操作只作用于当前项目。

忙碌、超过 500 项或包含已归档、已删除等受保护项目时，整批加急不可用；执行时再次核对全部项目，不跳过异常项目后部分修改。

怎样按筛选或勾选范围导出项目表？

先按状态、类型、首次新增日期和批次筛选，再打开“导出项目表”，选择“当前筛选结果”。需要挑选项目时，开启“批量选择”并勾选，再选择“已勾选项目”。两项都显示项目数；无勾选时“已勾选项目”不可用，不会导出全部。首次新增日期不随重复收件或状态变更改变。

Excel 包含名称、状态、类型、首次新增日期、收件批次编号、加急、截止日期、备注和范围说明。原单列待开发名单继续保留：在菜单选择“全部待开发名单（仅名称）”。导出可取消，不改变项目和材料。

怎样导出待开发项目名单？

打开“导出项目表”菜单，选择“全部待开发名单（仅名称）”，沿用原“导出名单”功能，选择 Excel 文件的保存位置。名单包含全部未归档、未删除的待开发项目。搜索、批次和其他筛选只影响当前清单。

工作簿只有“项目名称”一列，每个项目一行。没有待开发项目时，工作簿仍保留表头。

怎样查看工作量和导出交付表？

交付记录页保留日期和搜索，直接显示工作量合计及各类型数量。选中项目或明细后，从相应菜单调整工作量或纠正误记。点击“导出全部”可获取全部交付表，包含所有有效交付项目，独立于当前筛选。

同一批，还剩几个？

在原项目列表里查看同批颜色与编号，看清整批待完成数与总数，零也明确显示。项目沿用待开发、开发中、待交付、已交付四种状态。

查看安装与校验
怎样看这批还有多少待完成？

批次编号后显示待完成与总数。5 个项目中有 1 个进入待交付，显示“待完成4，共5”；1 个项目进入待交付，显示“待完成0，共1”。待完成只计待开发和开发中。选择批次可查看待交付、已交付明细。

待完成按整批项目的当前状态统计，同一个项目在一批中只计一次。搜索或筛选只改变清单，个人工作量单独统计。归档项目仍计入，删除的项目在恢复后重新计入。

同批标记，会改变项目顺序吗？

保留原排序，一项目一行，不按颜色重排，也不增加分组标题。相同批次使用相同编号和颜色；编号可直接识别，颜色只作辅助。原建项批次、项目身份和工作目录保持。

合并后怎样保留原批次？

误建项目改名并确认合并后，原建项批次不会被新收件批次遮住，两个批次都可查到这个项目。

之前已合并的项目，刷新即可恢复原批次，无须重做合并。连续合并同样适用；同批按项目只计一次，首次新增日期沿用保留项目，不改写历史材料和交付记录。

一个项目又收到新要求，怎样查看归属？

一个项目可以属于多个批次，同名项目沿用原身份与当前状态。每行最多显示两个编号，更多归属显示“+N批”；通过提示查看完整批次。文件先建项、后来整批粘贴时，已有项目和同次新项目共享这次收件标记。

怎样找到同一批项目？

使用编号搜索或批次筛选，查看同一收件关系中的项目，也可结合原状态筛选。标记只帮助定位，不移动目录、不改项目状态；选择、右键、双击和批量项目操作沿用原入口。

交付记录还能全部导出吗？

保留全部交付表，交付项目按项目去重，补充与界面一致的收件批次编号。首次有效交付、补交、排除个人工作量及撤销的口径保持，原有交付历史和既有历史附表保留。

反馈使用问题 ↗
工作箱适合什么样的工作？

适合在 Windows 上反复接收项目、整理文档或代码、打包交付的个人工作。它把项目、工作目录、文件版本和交付记录放在一起，方便继续修改与回查。

会自动读取微信消息，或上传我的文件吗？

不会读取微信或监控剪贴板。由你主动粘贴项目消息、拖入材料或选择文件。项目和归档保存在本机，官网不接收你的项目文件；工作箱不提供自动云同步。

还没建项目，就拖进文件或 ZIP，会怎样？

默认开启自动建项。完全未匹配、名称可安全识别时，会新建项目和工作目录并复制收录。出现多个匹配、名称冲突或合包项目不完整时，需要你核对。关闭自动建项后，先创建或选择项目。

文字项目列表支持 APP 名称；已登记项目的文件、ZIP 和目录可带下划线后的任意附注，完整项目名优先。匹配统一项目名末尾 APP 前的空白和大小写，保留原显示名、编号和工作目录。新项目名称不会按任意附注自动裁剪；历史同名编号、已归档或已删除项目仍需核对，不自动合并。

文件、文件夹和 ZIP 的交付状态有什么区别？

普通文件收录成功后为“待交付”；文件夹里的 ZIP 走同样的 ZIP 检查流程。通用模式下由你人工确认交付；选择自动模式后，初始门槛为每项目 4 个实际文件，子目录内的文件也计入，目录本身不计。多项目包分别判断，门槛可以调整。

只有 Word，没有压缩包，可以确认交付吗？

可以。在项目右键菜单人工确认交付，工作箱会将项目工作文件复制到独立归档版本，保留相对路径和文件名。工作目录只保留当前文件，旧稿移到同一磁盘上的独立历史区。已有旧稿须明确选择后确认整理，不会按文件名自动清理。归档只包含当前文件，既有交付归档和记录保留。归档成功后再记录交付，不要求一定有 ZIP。

已交付项目又修改了，今天会重复计数吗？

不会因为补交而重复计数。同一项目只在首次有效交付日计入交付数，后续交付继续留明细。可单独排除项目的个人工作量计数，状态、交付记录和归档保留；恢复资格后回到最早仍有效交付日，不会把旧项目记到今天。撤销交付记录是另一项操作，会让项目退回“待交付”。统计日期使用北京时间。

项目类型和工作量计数会互相影响吗？

不会。项目类型是自定义分类，可新增、改名、停用或启用，并用于筛选、右键和批量分配；预设“生成材料”“可运行”，已有同名类型保留原内容和启用状态；未分类旧项目保持原样，计数资格单独设置。停用类型仍可用于筛选已有归类。

归档分类按什么规则判断？

在“高级设置 → 归档分类”可按最近一次有效交付的单项目归档文件数设置规则。新安装预设恰好 16 个文件归为“可运行”，其他已知数量归为“生成材料”，数量未知时保留原分类。“可运行”是项目类型，文件数只能作为分类依据，实际运行需单独验证。

新安装的自动分类默认关闭。升级沿用原有配置，旧规则仍按“至少”比较。要调整已有归档的分类，先按当前规则预览，再确认应用。ZIP 自动交付另有门槛，自动模式初始为每项目 4 个实际文件。

误点交付或删除项目，还能恢复吗？

撤销误记会让项目退回“待交付”；排除个人工作量计数则保留“已交付”状态、交付事实、原文件和归档，两者用途不同。恢复已撤销交付记录只恢复统计有效性，不自动改变当前项目状态。删除项目会移入“已删除”，可以恢复，不删除目录和历史文件。

退出以后，还会自动归档吗？

不会。“退出”会停止程序和监视任务。“后台运行”会保留托盘入口并继续归档。自动归档只监视已登记的工作目录和主动提交的 ZIP，默认等文件稳定 10 秒后再复制。

下载失败，或换一台电脑使用怎么办？

下载失败可使用 正式安装版的 GitHub 备用下载。新电脑安装后不会自动带上旧电脑数据；如需迁移，请备份并迁移项目数据、对应工作和归档目录及全部已登记历史文稿目录（可能仍在原工作位置），迁移后核验路径与历史文件可读性。
