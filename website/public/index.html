桌面上的收件入口

拖到悬浮球，收进工作箱。

不用先打开管理面板。
把手头的项目文字或材料，拖到桌面悬浮球上。

项目文字 → 建项目

选中项目文字拖入，核对项目清单后，创建项目和对应工作目录。也可以右键选择“粘贴项目消息”。

文件 / 整个文件夹 / ZIP → 收材料

材料按项目名称和命名规则匹配，复制收录，原件保留；文件夹保留相对目录。遇到归属歧义，先由你核对选择。

来源须是可访问的实际文件或目录，可读取的共享盘、映射盘也能收；网址和虚拟附件不支持，请先把附件保存为文件。普通文件收录成功后为“待交付”，ZIP 等待稳定后归档，是否自动交付按当前模式和门槛判断。

悬浮球怎么用

单击打开 · 按住移动
单击打开项目管理面板；按住移动悬浮球，放到顺手的位置。
右键打开更多操作
粘贴项目消息、选择文件收进项目、打开 ZIP 归档目录，也可以后台运行或退出 WorkBox。
角标与进度
角标显示未交付项目数；收件忙碌时，悬浮球外圈显示处理进度。

收件反馈框怎么看

“查看”定位本次结果
打开本次涉及的项目；需要核对 ZIP 时，转到对应的 ZIP 页面。
“收起”仅隐藏提示
不会停止收件。处理中可点“取消处理”，保留已完成项，原件继续保留。
关闭、后台和退出
关闭管理面板，悬浮球仍在；后台运行隐藏面板和悬浮球，保留托盘与归档监视，点击托盘可恢复。托盘不可用时保留可见悬浮球。退出 WorkBox 会等待当前文件操作安全结束，再停止程序和监视。

反馈使用问题 ↗
工作箱适合什么样的工作？

适合在 Windows 上反复接收项目、整理文档或代码、打包交付的个人工作。它把项目、工作目录、文件版本和交付记录放在一起，方便继续修改与回查。

会自动读取微信消息，或上传我的文件吗？

不会读取微信或监控剪贴板。由你主动粘贴项目消息、拖入材料或选择文件。项目和归档保存在本机，官网不接收你的项目文件；工作箱不提供自动云同步。

还没建项目，就拖进文件或 ZIP，会怎样？

默认开启自动建项。完全未匹配、名称可安全识别时，会新建项目和工作目录并复制收录。出现多个匹配、名称冲突或合包项目不完整时，需要你核对。关闭自动建项后，先创建或选择项目。

文件、文件夹和 ZIP 的交付状态有什么区别？

普通文件收录成功后为“待交付”；文件夹里的 ZIP 走同样的 ZIP 检查流程。通用模式下由你人工确认交付；选择自动模式后，初始门槛为每项目 4 个实际文件，子目录内的文件也计入，目录本身不计。多项目包分别判断，门槛可以调整。

只有 Word，没有压缩包，可以确认交付吗？

可以。在项目右键菜单人工确认交付，工作箱会将项目工作文件复制到独立归档版本，保留相对路径和文件名。归档成功后再记录交付，不要求一定有 ZIP。

已交付项目又修改了，今天会重复计数吗？

不会因为补交而重复计数。同一项目只在首次有效交付日计入交付数，后续交付继续留明细。撤销早期记录后，会按剩余有效记录重新确定首次交付；统计日期使用北京时间。

误点交付或删除项目，还能恢复吗？

交付记录可撤销，项目自动退回“待交付”，原文件和归档保留。恢复交付记录只恢复统计有效性，不自动改变当前项目状态。删除项目会移入“已删除”，可以恢复，不删除目录和历史文件。

退出以后，还会自动归档吗？

不会。“退出”会停止程序和监视任务。“后台运行”会保留托盘入口并继续归档。自动归档只监视已登记的工作目录和主动提交的 ZIP，默认等文件稳定 10 秒后再复制。

下载失败，或换一台电脑使用怎么办？

下载失败可使用 GitHub 备用下载。新电脑安装后即可使用，但不会自动带上旧电脑数据。如需迁移，请备份并迁移项目数据和对应工作、归档目录；反馈问题时请移除个人信息与真实项目资料。
