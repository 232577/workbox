开始使用

从桌面上的
一个小入口开始。

悬浮球收件，点击打开管理面板。项目操作在项目行的右键菜单里。

归档和交付操作保留原文件。不同版本与交付记录各自留存，方便回看。

  1. 收下项目

    把项目消息粘贴或拖到悬浮入口，确认项目与目录。也可以通过面板的收件入口选择文件。

  2. 整理工作文件

    拖入文件，核对归属项目。有歧义时手动选择；进入工作目录继续编辑，ZIP 按版本归档。

  3. 跟进与确认交付

    在项目行右键打开目录、调整状态或确认交付。误记可撤销，项目自动回到待交付，原文件与归档仍然保留。

使用前了解

常见问题

需要账号或登录吗？

不需要。安装后直接使用，项目、工作文件和归档数据保存在本机。

安装包会带上其他人的项目吗？

不会。公开安装包为干净安装，不包含已有项目、工作文件或归档数据。

升级时怎样保留数据？

先备份现有安装目录中的 data 文件夹；如果另外设置了工作目录或归档目录，也请一并备份。完全退出 WorkBox 后，在原安装位置安装新版本。不要用干净安装包中的内容覆盖已有 data。

会自动读取微信消息吗？

不会。需要你主动粘贴或拖入项目消息，也可以通过文件选择入口收进文件。

撤销交付会删除文件吗？

不会。撤销误记会修正交付统计，并把项目恢复为待交付；原文件、归档文件和历史记录均保留。恢复记录只恢复统计有效性，不自动将项目改为已交付。

下载失败或遇到问题怎么办？

可尝试 GitHub 备用下载。使用问题可到 GitHub Issues 反馈；提交前请移除个人信息和真实项目资料。
